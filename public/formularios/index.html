Formularios de Salida — Sistema de Gestión

Catálogo de documentos operativos de BM Metalúrgica, en versión imprimible para completar a mano durante la transición al ERP. Cada formulario lleva su código de plantilla FO-ÁREA-NN y, al llenarse, un número correlativo MBM·TIPO·AÑO·NNNN. Los campos replican los que el sistema va a capturar: el papel de hoy es la especificación de cada pantalla del mañana.

Comentarios en vivo: al pie de cada formulario podés dejar comentarios (qué campo falta o sobra). Se guardan en el servidor y quedan compartidos entre todos y visibles al instante. Trazabilidad de gastos: los formularios de costos (Órdenes, Compras, Almacenes, Caja Chica, Combustible, Herramientas) piden siempre el proyecto imputado, para poder rastrear cada peso hasta su obra. Las áreas con a validar aún no tienen módulo en el ERP: sus campos vienen del organigrama y la práctica.

Procedimiento — Ciclo de un Proyecto

Este es el circuito que sigue todo proyecto, desde que se acepta el presupuesto hasta el cierre financiero. Se ejecuta hoy de forma manual con los formularios (mientras se termina el ERP). Cada paso indica el responsable y el formulario que usa (tocá el código para ir a la hoja).
Gerencia Control de Procesos y Calidad Oficina Técnica Fábrica Cliente Calidad / Financiero
  1. 1
    Gerencia

    Presupuesto aceptado

    El gerente deriva el proyecto aceptado a Control de Procesos y Calidad.

  2. 2
    Control de Procesos y Calidad

    Apertura del proyecto

    Rellena la Apertura de Proyecto y adjunta el Brief / pedido del cliente, planos y detalles. Imprime la planilla de Visita de Obra. Pasa todo a Oficina Técnica.

    FO-PY-01FO-OT-01FO-OT-03
  3. 3
    Oficina Técnica

    Ingeniería de fabricación

    Genera los planos de fabricación y el desglose de materiales. Devuelve todo a Control de Procesos y Calidad.

    FO-OT-04
  4. 4
    Control de Procesos y Calidad

    Control y Orden de Fabricación

    Controla que estén todos los datos completos. Genera la Orden de Fabricación (adjunta planos de fabricación + detalles pedidos por el cliente). Revisa la fecha de recepción de materiales del proyecto.

    FO-PD-01
  5. 5
    Fábrica

    Fabricación

    Se fabrica. El registro se hace por el informe diario del personal (por trabajador).

    FO-PD-02
    ⚠ No se registra por proyecto: la fábrica es una LÍNEA DE PRODUCCIÓN MULTIPROYECTO. El avance de cada proyecto se arma después con las horas/tareas del parte diario.
  6. 6
    Fábrica → Calidad

    Fin de fabricación

    Terminada la fabricación, se informa a Control de Procesos y Calidad.

  7. 7
    Control de Procesos y Calidad

    Orden de Trabajo de Obra

    Genera la Orden de Trabajo de Obra para el montaje/entrega.

    FO-OB-01
  8. 8
    Cliente

    Recepción

    El cliente (o su encargado) firma el Acta de Recepción. Se entrega a Calidad para registrarla.

    FO-OB-04
  9. 9
    Calidad / Financiero

    Cierre financiero del proyecto

    Se hace la Evaluación Financiera del Proyecto: se consolidan TODOS los gastos imputables al proyecto y se incluye el % de gasto administrativo, para sacar el costo real y verificarlo contra el presupuestado. Aquí termina el ciclo.

    FO-FI-01
