Procedimiento de un Proyecto

Ciclo completo · requisitos para avanzar en cada etapa
Gerencia Control de Procesos y Calidad Oficina Técnica Fábrica Cliente Calidad / Financiero Requisito para avanzar
Código de proyecto: se genera en la Apertura de Proyecto (etapa 2 · FO-PY-01) y es el número al que se referencian y con el que se trazan TODOS los formularios del proyecto.
1
Gerencia
Aceptación
El gerente deriva el proyecto aceptado a Control de Procesos y Calidad.
sin form.
Para avanzar ✔ Cotización aceptada y firmada por el cliente.
▼
2
Control de Procesos y Calidad
Apertura del proyecto
Abre el proyecto y adjunta el brief/pedido del cliente, planos y detalles. Imprime la visita de obra. Pasa a Oficina Técnica.
FO-PY-01FO-OT-01FO-OT-03
Para avanzar ✔ Apertura completa + brief, planos y detalles adjuntos.
▼
3
Oficina Técnica
Ingeniería de fabricación
Genera los planos de fabricación y el desglose de materiales. Devuelve a Control de Procesos y Calidad.
FO-OT-04FO-OT-05
Para avanzar ✔ Planos de fabricación emitidos + desglose de materiales completo.
▼
4
Control de Procesos y Calidad
Orden de Fabricación
Controla que estén todos los datos completos. Genera la orden de fabricación (adjunta planos + detalles del cliente). Confirma la fecha de recepción de materiales.
FO-PD-01
Para avanzar ✔ Datos controlados + orden con planos adjuntos + materiales con fecha confirmada.
▼
5
Fábrica
Fabricación
Se fabrica. El registro se hace por el informe diario del personal (por trabajador) — la fábrica es una línea de producción multiproyecto.
FO-PD-02FO-PD-03FO-PD-06
Para avanzar ✔ Fabricación terminada + inspección de calidad conforme (FO-PD-03) + partes diarios cargados. Se informa a Calidad.
▼
6
Calidad → Cliente
Obra y Recepción
Se genera la orden de trabajo de obra. El cliente (o su encargado) firma el acta de recepción. Calidad la registra.
FO-OB-01FO-OB-04
Para avanzar ✔ Acta de recepción firmada por el cliente y registrada.
▼
7
Calidad / Financiero
Cierre financiero
Evaluación financiera del proyecto: se consolidan todos los gastos imputables + el % de gasto administrativo, para sacar el costo real y verificarlo contra el presupuestado.
FO-FI-01
Cierre ● Evaluación financiera completa → proyecto cerrado.
